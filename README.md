# Data Structures & Algorithms in Java

A collection of Data Structures and Algorithms solutions implemented in Java.

## Overview

This repository documents my journey of learning and practicing Data Structures and Algorithms using Java. The solutions are organized topic-wise and are based on Striver's A2Z DSA Sheet.

The goal of this repository is to strengthen problem-solving skills, improve coding proficiency, and prepare for software engineering internships and technical interviews.
